# Regras de bibliotecas de ícones

- Use **Phosphor Icons** (`@phosphor-icons/react`) para novas áreas de marketing, conceitos, benefícios e ilustrações da landing.
- Use **Tabler Icons** (`@tabler/icons-react`) quando o ícone representar ação, navegação, código, arquivo ou estado de produto.
- Não misture famílias no mesmo grupo visual; escolha uma família por componente.
- Não use Lucide, `react-icons`, emoji ou SVG manual para novos ícones.
- Use `currentColor`, tamanhos entre 14–24px na UI e `aria-hidden` quando existir label textual.
- Ícone sem texto precisa de `aria-label`, tooltip quando necessário e alvo mínimo de 36px.
- Preserve peso/estilo consistente da família escolhida e registre exceções no PR.
